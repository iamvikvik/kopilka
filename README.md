# Копилка

Личное приложение для накоплений: несколько целей (рубли или дирхамы), сроки, календарь пополнений, график и темп, отчёты по месяцам и годам. Работает без интернета, данные хранятся только на телефоне.

## Как выложить
1. На github.com создайте репозиторий `kopilka` (Public).
2. Add file → Upload files: загрузите все файлы из этой папки → Commit changes.
3. Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)` → Save.
4. Адрес: https://ВАШ_ЛОГИН.github.io/kopilka/
5. В Safari: «Поделиться» → «На экран “Домой”».

Цели и суммы в код не вписаны: репозиторий публичный. Цели добавляются в самом приложении.

## Как обновить
Add file → Upload files → новые файлы с теми же названиями → Commit changes. Подождите 1–2 минуты и полностью перезапустите приложение.

## Файлы
- `index.html` — приложение
- `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — значок
- `sw.js` — работа без интернета (при правках поднимайте номер в `CACHE`)
